Flight activity is pulled by a GitHub Actions job every 12 hours from the OpenSky Network (real ADS-B departures seen at VGHS in the last 13 hours) and committed to data/flights.json in this repo. Fares are pulled the same way from the Amadeus Self-Service Flight Offers Search API into data/fares.json — real quoted prices for a departure ~2 weeks out, median across the offers returned, not a live booking price. Because this page reads those files same-origin, there's no browser CORS/sandbox issue like there is inside a Claude.ai artifact.
